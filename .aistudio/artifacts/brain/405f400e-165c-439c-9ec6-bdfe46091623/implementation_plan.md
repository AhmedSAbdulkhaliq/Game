# لعبة تسلق التلال الفيزيائية (Hill Climb Physics 2D)

لعبة قيادة وتحدي ثنائية الأبعاد متكاملة ومستوحاة من أسلوب "Hill Climb Racing"، تعتمد على محرك فيزيائي سلس (Rigid Body Physics مع عجلات ونوابض تعليق وتوليد تضاريس إجرائي)، وتوفر بيئات متعددة، ترقيات للمركبات، ونظام وقود وأصوات ديناميكية.

---

### مراجعة المستخدم والقرارات المؤكدة (User Review & Confirmed Decisions)

> [!IMPORTANT]
> تم تأكيد الخيارات الرئيسية التالية وفق إجاباتك في المرحلة الأولى:

- **البيئات والتضاريس**: إتاحة 3 بيئات فريدة (الريف الريفي الكلاسيكي بتلال خضراء، الصحراء بكثبان رملية متموجة، والقمر الفضائي بجاذبية منخفضة وأرض رمادية حالمة).
- **المركبات ونظام التطوير**: توفير 3 مركبات مميزة (جيب كلاسيكي Classic Jeep، شاحنة عملاقة Monster Truck، ومستكشف القمر Lunar Buggy) مع متجر ترقيات بـ 4 مسارات تطوير (المحرك Engine، الإطارات Tires، التعليق Suspension، خزان الوقود Fuel Tank) باستخدام العملات المجمعة.
- **الصوت التفاعلي الديناميكي**: نظام صوتي تخليقي متقدم ومبني كلياً على Web Audio API (محاكاة دورات المحرك RPM، صوت التزود بالوقود، رنين جمع العملات، صوت هبوط التعليق والاصطدام) دون الحاجة لملفات صوتية خارجية قابلة للتلف.
- **اللغة والواجهة**: واجهة مستخدم متناسقة ثنائية اللغة تدعم العربية والإنجليزية مع لوحة تحكم باللمس للشاشات الذكية ومفاتيح لوحة المفاتيح للحاسوب.

---

### 1. نظرة عامة والفكرة الجوهرية (Overview & Core Concept)

- **طبيعة التجربة**: لعبة تسلق وقيادة تعتمد على التوازن الحرج للسيارة فوق تلال وعرة لا متناهية، حيث يتناقص الوقود باستمرار بينما يجمع اللاعب العملات وبراميل الوقود ويتجنب انقلاب السائق على رأسه أو نفاد الخزان.
- **الفئة المستهدفة**: عشاق ألعاب الفيزياء والمهارة والسرعة في المتصفح، مع تجربة لعب فورية وسريعة الإيقاع (Pick up & Play).
- **القيمة الأساسية**: متعة محاكاة القصور الذاتي، القفز في الهواء مع الدوران البهلواني (Air Flips)، وموازنة السرعة مع استهلاك الوقود وترقية مواصفات المركبة للوصول لمسافات قياسية جديدة.

---

### 2. تجربة المستخدم والتصميم البصري (User Experience & Visual Design)

#### تدفق المستخدم (User Flows)
1. **شاشة البداية (Title Screen & Garage)**:
   - عرض المركبة الحالية، رصيد العملات، وأفضل مسافة قياسية.
   - اختيار البيئة (ريف / صحراء / قمر).
   - اختيار المركبة والترقيات عبر لوحة كراج واضحة وسريعة.
   - زر "انطلاق / بدء اللعب" وزر كتم/تفعيل الصوت.
2. **شاشة اللعب المباشر (Active Gameplay Canvas)**:
   - مساحة لعب بنسبة 90% خالية وغير محجوبة.
   - مؤشر وقود تناظري/رقمي دائري أو شريطي أنيق مع تحذير وميضي عند اقتراب النفاد.
   - عداد السرعة (كم/ساعة) والمسافة المقطوعة (متر) ورصيد العملات المجمعة.
   - مؤشرات تحكم باللمس في أسفل الشاشة (دواسة البنزين/الميل للخلف، ودواسة الفرامل/الميل للأمام) مع دعم مفاتيح الأسهم أو `A/D` أو `W/S`.
3. **نهاية الجولة (Game Over / Level Summary)**:
   - تفعيل شاشة نهاية الجولة عند انقلاب السائق ومست الرأس الأرض أو عند نفاد الوقود وتوقف السيارة.
   - استعراض المسافة المقطوعة، العملات المكتسبة، مكافآت الحركات الهوائية (Flips)، مع إمكانية الترقية أو إعادة المحاولة فوراً بضغطة زر واحدة دون إعادة تحميل الصفحة.

#### الهوية البصرية وتصميم التضاريس
- **محرك التضاريس الإجرائي (Procedural Terrain)**: توليد مستمر لمنحنيات بيزيه وشرائح السطح باستخدام خوارزميات التموج الجيبي المزدوج (Multi-frequency Perlin/Sine Splines)، مما يضمن تنوع المرتفعات والمنحدرات والقفزات.
- **تنوع الخلفيات والبارالاكس (Parallax Layers)**: 3 طبقات خلفية تتحرك بنسب سرعة مختلفة (غيوم/جبال بعيدة/تلال متوسطة) تعطي عمقاً بصرياً ممتعاً.
- **التصميم والألوان**:
  - ريف: سماء زرقاء دافئة، عشب أخضر زمردي مع طبقات ترابية عميقة.
  - صحراء: شمس حارقة، سماء برتقالية ذهبية، كثبان رملية صفراء دافئة.
  - قمر: فضاء مظلم مع نجوم متلألئة، كواكب في الأفق، وسطح قمري صخري منخفض الجاذبية.
- **الطباعة**: أرقام رقمية جدولية واضحة (`tabular-nums`) لقراءة سلسة للسرعة والمسافة، وخط عربي/لاتيني رياضي نظيف.

### 3. القرارات التقنية والهندسية (Key Architectural Decisions)

- **محرك الفيزياء (Rigid-Body Simulation)**:
  - استخدام نظام محاكاة فيزيائي مخصص ثنائي الأبعاد مستقر وسريع 60fps (أو نموذج مبسط من Matter.js/Verlet physics) مع نقاط تلامس العجلات، تعليق نوابض ومخمدات (Spring-Damper Suspension)، قوى احتكاك السطح، والعزم الدوراني للمحرك (Torque).
  - هذا النهج يضمن عدم وجود أي مشاكل توافقية في الحزم، واستقراراً تاماً عند سرعات الإطارات العالية دون اختراق العجلات للتضاريس.
- **إدارة تضاريس لا نهائية (Infinite Chunk Streaming)**:
  - تقسيم التضاريس إلى مقاطع (Chunks) تُبنى وتُفرغ تلقائياً حول موضع السيارة لحفظ الذاكرة وثبات معدل 60 إطاراً في الثانية.
- **حفظ التقدم محلياً (Local Storage Persistence)**:
  - حفظ العملات، المستويات القياسية لكل بيئة، ومستويات ترقيات المركبات في `localStorage` بحيث لا يفقد اللاعب إنجازاته عند العودة للتطبيق.
- **نظام المؤثرات الصوتية (Procedural Web Audio)**:
  - مولد ذبذبات المحرك (Engine Synth) يغير تردده وعمقه حسب ضغط البنزين وسرعة الدوران.
  - صدى اصطدام هيدروليكي ونغمات جمع العملات وبراميل الوقود.

### 4. المخطط المعماري للنظام (System Architecture & Data Strategy)

```
┌────────────────────────────────────────────────────────────────────────┐
│                        App.tsx (Main Controller)                       │
├────────────────────────────────┬───────────────────────────────────────┤
│    GameState:                  │    SoundManager:                      │
│    TITLE | PLAYING | GAMEOVER  │    Web Audio Synthesis Engine         │
└───────────────┬────────────────┴───────────────────┬───────────────────┘
                │                                    │
       ┌────────┴────────┐                  ┌────────┴────────┐
       ▼                 ▼                  ▼                 ▼
┌──────────────┐  ┌──────────────┐   ┌──────────────┐  ┌──────────────┐
│  GarageView  │  │  GameCanvas  │   │   HUDView    │  │ GameOverView │
│ - Vehicles   │  │ - Physics    │   │ - Fuel Gauge │  │ - Stats      │
│ - Upgrades   │  │ - Terrain    │   │ - Speed/Dist │  │ - Coins      │
│ - Stage Pick │  │ - Particles  │   │ - Pedals     │  │ - Quick Retry│
└──────────────┘  └──────────────┘   └──────────────┘  └──────────────┘
```

#### الكائنات والبيانات الأساسية:
- `VehicleState`: موضع الهيكل والزوايا، سرعة العجلات، قوة الدفع، ومرونة التعليق.
- `TerrainSegment`: قائمة النقاط الإجرائية لكل قطاع مع تصادم متعدد الأضلاع وتعبئة الألوان والتدرجات.
- `PickupItem`: براميل الوقود (+100% أو +50%)، والعملات الذهبية ذات القيم المتنوعة موزعة في الهواء وعلى التلال.
- `UpgradesState`: مستويات المحرك (Engine: 1-10)، الإطارات (Grip: 1-10)، التعليق (Suspension: 1-10)، وخزان الوقود (Capacity: 1-10).
